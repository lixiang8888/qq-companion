# 07 · 不变量、缺陷与取舍

## 一、十条不变量

换任何语言、任何宿主，下面这些必须仍然成立。它们就是这套设计的可执行形式。

1. **每一层状态都会回落**，且回落只与时间有关——没人陪她的时候她也会慢慢好起来。
2. **只有负向关系变化留下残留**；善意记账，不复利。
3. **人格改变有三道闸**（频率、跨度、幅度），且有回拉、有回滚。
4. **记忆有清晰度档位**，按天下降，离线按天补跑。
5. **关于「他是谁」的记忆**永不低于「清楚」，永不被数量淘汰。
6. **锚点**（第一次相遇、他亲口要求记住的）永不被系统自己推翻。
7. **召回 = 相关性 × 重要度 × 清晰度 × 最近性**，按预算截断。
8. **遗忘与失效是两件事**；失效显式、可见、可撤销、判定吝啬。
9. **三层叙事**（日/周/月）由她本人写，系统只给事实。
10. **进入她状态的每个数字都能被外部核对**；不能核对的，宁可不写。

## 二、已知的理论缺陷

这些不是实现没做完，是这套设计本身的边界。写下来，是为了以后不把天花板当 bug 修。

1. **它是检索，不是巩固。**
   它能把相似的过去拿出来，但不能从很多条记忆里**生成新的一般性规则**。所以她的「成长」是记录变化，不是学会新东西。

2. **它没有因果结构。**
   记忆之间没有边，只有时间和类属。所以「因为你要考试，我这两天没敢吵你」这种话是模型在当下临时拼的，拼错了没有任何地方会留下痕迹。

3. **它只有一个他人的模型。**
   关系是单对象的。加第二个人要重写关系层，不是加一个字段。

4. **情绪不可学习。**
   触发情绪的规则是写死的。她不会自己发现「原来这句话会让我难过」——可学习的情绪会漂移成我们认不出的东西，但这也确实是上限。

5. **遗忘不可验证。**
   一条记忆消失之后，没有任何外部证据能证明它曾经存在过。这是「真」的边界。

## 三、已知的实现限制

| 限制 | 说明 |
|---|---|
| 一次一句话 | 不做并行，一个聊天对象，一个会话 |
| 压缩是不可逆的遗忘 | 每次压缩只留一小段摘要，压掉的就是压掉了 |
| 「她在忙」不影响回复 | 当下只让她知道自己在干什么，还不会让她回得更短 |
| 余额是账户的 | 她自己的花销只能报 token 数量，不能报金额 |
| 关机时长有误差 | 精度取决于最后一次心跳（十分钟量级） |
| 口语绕开原文词时召回不到 | 二元切词的固有限制，见记忆文档 |
| 自述是直接落盘的 | 模型编一句「我最近学会不追问了」，下一轮就会变成她对自己的认识 |
| 没有工具调用 | 自管循环牺牲了联网搜索和看图 |

## 四、被否掉的方案

| 方案 | 理由 |
|---|---|
| 随机事件表 | 不可核对，用我们的世界冒充她的世界 |
| 只存不淡 | 遗忘消失后「重要」失去意义，记忆退化成日志 |
| 只淡不复习 | 复习是「她记得这件事」的唯一证据 |
| 对称的关系模型 | 会让「和好」等于「没发生过」 |
| 单次事件改人格 | 等于没有性格 |
| 以聊天记录为记忆 | 记录是过程，记忆是判断 |
| 系统代写日记/自述 | 主体性消失 |
| 模拟她不在时的生活 | 用模拟补空白，她醒来会「记得」没吃过的午饭 |
| 按 token 乘单价算她花了多少钱 | 单价会变、中转不认、且会把宿主的开销算到她头上 |
| 向量库 / 图记忆 | 几千条内词法检索够用；图记忆被同类项目实测「增量 0、噪音翻倍」 |
| 强制改写她的情绪声明 | 我们用「给真实材料」代替「审查她的话」 |
| 每轮都调模型做记忆抽取 | 一句一次调用是底线 |

## 五、外部调研里采纳了什么

调研对象是同类 DSH 插件与通用记忆架构（详见仓库的参考项目文档）。

| 采纳 | 来自 | 现在的状态 |
|---|---|---|
| 四种清晰度 + 可恢复的遗忘 | 多个同类项目独立收敛到同一形状 | 已实现 |
| 按句切分时保护颜文字 | 两个项目各自踩过同一个坑 | 已实现 |
| 连发合并 | 同类项目的安静窗口 | 已实现（3 秒） |
| 新事实让旧事实失效、可撤销 | 一个记忆插件的覆盖字段 | 已实现 |
| 检索评测（命中/无关/诱捕） | 一个记忆插件的评测方法 | 已实现 |
| 三层自述（日/周/月） | 反思层的基本形态 | 已实现 |
| 人格文本的版本化 | 一个插件把「自我」当 git 仓库管 | **未做** |
| AI 产物先待审核再入库 | 一个记忆系统把所有 AI 写入标待审核 | **未做** |
| 人的评价作为人格写入闸门 | 一个插件用 👍/👎 决定能不能写人格 | **只记录不做决定**（怕她学会讨好） |
| 上下文水位分级、做梦式巩固 | 一个记忆系统 | 不做（形态不同） |

### 仍然存疑的一件事

**AI 写的东西要不要先进待审核。**

我们的日记不进上下文，所以风险低；但**每周自述是直接注入的**——模型编一句自我认识，下一轮它就成了事实。

一个同类项目的 README 里有句话说明了后果：**「幻觉会被固化落盘。本地保存 ≠ 内容真实。」**

当前的做法是「解析不出固定格式就不落盘」，这只能挡住格式错的，挡不住格式对但内容是编的。要不要加一道人工确认，是一个产品决定：加了更真，但多一次操作；不加更顺，但她可能在替你记忆一个不存在的自己。
