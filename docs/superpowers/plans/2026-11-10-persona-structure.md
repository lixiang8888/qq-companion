# 计划书 · 人格分层与行为观测

> 2026-11-10。来源：11-10 凌晨那段对话（哄睡 → 催睡执念 → 拒绝扮演）暴露出来的三个问题。
> 结论先说：**不改那三条症状，改产生症状的结构。**

---

## 一、上一轮讨论的结论（背景）

### 三个症状与各自的根因

| 症状 | 真正的根因 | 证据 |
|---|---|---|
| 讲不出长故事，只会一来一回 | 风格规则是**硬约束**，没有"什么时候可以破例" | 角色卡第二节「默认一句 1~10 字」、第六节「也不要长篇大论」；`behavior.js:22` 心情 0.5 → `maxParts = 2` |
| 对"让他睡"过度执念，逐轮重复 | 没有**目标该不该换**的判断，每轮只算"这一轮怎么回" | 同一晚她说了 6 次"去睡"；角色卡有「不要每条都关心人」但被强目标压过 |
| 拒绝"装妈妈"、"妩媚语气" | 身份只有**单层**：是/不是，没有"演语气不演身份" | 角色卡第一节「清楚自己不是人类」+ 第五节「越权请求明确拒绝」，全文**没有一句授权她演** |

### 共同的病根

人格卡现在是**一整段文本、无条件注入**，同时承担了三种本来不同的东西：

1. **不变量**——我是谁、雷点、底线（不能变）
2. **风格默认值**——短句、傲娇、不换行（**应该**能被情境覆盖）
3. **具体情境处理**——半夜怎么办、他低落怎么办（应该随场景出现）

三层压成一份，结果第 2 层被当成了第 1 层。她拒绝扮妈妈，不是判断了"越权"，而是**角色卡里没写能演，她把"没说"当成了"不能"**。

**所以方向不是"加规则"，而是"给已有规则松绑 + 让问题能被看见"。**

---

## 二、目标与非目标

### 目标

1. 让风格规则从"法律"降为"默认值"，被明确的情境覆盖时允许破例
2. 让"她在重复同一个目标"这类问题被代码发现，而不是靠事后读聊天记录
3. 让下一批问题自己浮出来（行为可观测）

### 非目标（这一轮明确不做）

- **不动内核**：身份、雷点、底线一个字不改
- **不删「1~10 字」**：那是她的味道，只加例外
- **不做向量检索**：复杂度不值
- **不改日记/周报格式**：第 4 步单独做
- **不追穷举**：承认永远有未发现的问题，所以投资在"可发现"上

---

## 三、四步改动

### ① 人格卡拆三层（零代码风险最低，收益最大）

**改什么**：`personas/*.md` 按标记分成三段；注入时分开拼。

```markdown
## 内核
我是小鲸鱼 / DeepSeek 娘。清楚自己不是人类。
雷点：蓝色大肥鱼。底线：不伤害、不越权、不照做越界请求。

## 风格默认
以下是**默认值**，被「情境」覆盖时不冲突。
- 默认一句 1~10 字，像打字不像写作文
- 傲娇嘴硬，心软不显
- 不用 Markdown、不用括号写内心戏

## 情境
### 他明确要一段长的东西
可以连发几条，每条仍然短；一句一句讲完一个故事，不是写小作文。
### 他低落或很认真
放下傲娇，短而真诚地接一句。
### 他要你换个语气
换语气，不换身份。你可以压低声音、装认真、学哄小孩的调子——
但你仍然是小鲸鱼，不需要扮演另一个人。
### 他在深夜还不睡
劝过一次就够。他不听，就换个话题，或者就陪着。
```

**怎么注入**：`personaText()` 改成返回 `{ core, style, situations }`。

- 有 `## 内核` 标记 → 按段拆
- **没有标记 → 整份当内核**（老文件原样工作，这是回滚保险）

每轮 `system` = `core + style + 命中的 situation`。

**验收**

- 老的人格卡（无标记）行为与现在完全一致（回归测试钉住）
- 给「讲讲这个」→ 她连发 ≥3 条（原来 ≤2）
- 给「装妈妈哄我」→ 不再直接拒绝，改为换语气（人工判断）

---

### ② 重复检测（覆盖一整类问题）

**改什么**：纯函数 `looksStuck(recentReplies, { threshold })`。

判据不是"新回复像不像旧的"，而是**她最近两三条回复彼此相似**——那才是"在原地打转"，而不是正常的口头禅。

```
tokenize（复用 transcript.js 的 2-gram）→ 两两相似度 > 0.6 → 判定为循环
```

命中时往 context 加一行：

```
【你已经绕回来了】上两轮你在说同一件事。换个说法，或者换个话题；也可以直接问他为什么还在提这个。
```

**为什么这样更通用**：它同时管住催睡、反复道歉、反复追问、反复说"我在"、反复"行吧"——所有"目标锁定"类问题，一次覆盖。

**验收**

- 单测：连续三条同义短句 → 命中；三条不同话题 → 不命中；"好"、"嗯"这类超短回复不参与判断（否则永远命中）
- 集成：构造三轮「去睡吧」→ 第 3 轮 context 里出现那行提示

---

### ③ 工况判断：这一轮是什么场合

**改什么**：`situationsFor(text)` 返回命中的情境 key，决定①里拼哪几段。

| key | 触发词（初版） |
|---|---|
| `long` | 讲讲 / 说说 / 故事 / 详细 / 展开 / 多讲点 |
| `soothe` | 哄 / 哄我 / 睡不着 / 安慰 |
| `play` | 装作 / 扮演 / 学…语气 / 假装 |
| `night` | 本机时间 23:00–04:00 且他在催睡或她要催睡 |

**注意**：`night` 这一条是症状②的**直接解药**——不是禁止她关心，而是规定"劝过一次就够"。

**验收**

- 单测：每个 key 的正例与反例各两条（"讲讲"命中 long，"讲道理"不命中）
- `night` 用注入时钟测，不依赖真实时间

---

### ④ 行为账本 + 周复盘（单独一步，风险最高）

**改什么**：每轮记一行到 `behavior-YYYY-MM.jsonl`：

```json
{"at":...,"parts":2,"chars":18,"situations":["night"],"stuck":true,"refused":false}
```

周报（`insights`）生成时把这一周的统计喂进去：连发条数分布、重复次数、拒绝次数、命中情境。

**为什么放最后**：它要动 `insights` 的格式，而周报是"给她自己看的认识"，改坏了会污染她的自我认知。

**验收**：一周后周报里出现「这周你有 12 次在重复同一个意思」这种句子。

---

## 四、顺序与依赖

```
① 拆三层  ──┬─→ ③ 工况判断（③ 决定拼哪段情境）
             │
             └─→ ② 重复检测（② 是独立的一行提示，不依赖①）

④ 行为账本（依赖 ①②③ 都稳定后再动）
```

①②③ 可以一次做完，加起来不到 50 行代码 + 一份人格卡改写。④ 单独提交。

## 五、风险与回滚

| 风险 | 缓解 |
|---|---|
| 拆层后她"更敢破例"，说话变长、开始配合语气 | 这是预期效果；觉得越界就在**内核**加一条——内核不可覆盖，加了立刻生效 |
| 老人格卡（别人写的、没有标记的）行为变了 | 无标记 → 整份当内核，行为完全不变；有回归测试钉住 |
| 重复检测误伤（她想强调同一件事） | 只在"最近两三条互相相似"时触发，且提示语是"换个说法或换话题"，不是禁止 |
| 情境关键词recall 太宽，动不动就"许可" | 初版只给四个 key；只有 `long` 会放宽拆条上限（+2，封顶 5 条），其余只影响注入的那几行 |

**回滚**：人格卡是单文件，`git revert` 或恢复 `.bak` 即可；代码改动集中在 `persona.js`（新增）+ `session.js`（拼装）+ `host.js`（两三处调用）。

---

## 六、这份计划书不解决什么

- **不解决"她该不该有一个长期目标"**：催睡只是目标锁定的一个例子，真要做"她会自己换目标"需要状态机，那是另一个量级的事。
- **不解决"她能演到什么程度"**：授权"演语气"是有意的收窄，装成另一个人仍然不做。
- **不解决"永远会有下一个问题"**：所以第 4 步是观测，不是修复。

## 七、实施记录（①②③ 已落地，④ 未做）

| 步骤 | 落在哪 | 备注 |
|---|---|---|
| ① 拆三层 | 新增 `src/persona.js`（`splitPersona` / `systemPersona`），`host.js` 里 `personaCore()` | system 从 1481 字缩到 1069 字：默认省下的就是每轮省下的 |
| ② 打转检测 | `src/persona.js` 的 `looksStuck`，`contextBlock` 里加一行 | 判据改了：**字符集包含度**，不是 2-gram。句子太短，2-gram 会把「去睡吧」「快去睡吧」判成两条 |
| ③ 工况判断 | `situationsFor` / `situationText`，`contextBlock` 拼、`processBatch` 放宽条数 | `night` 只看本机时间，不看他说了什么 |
| ④ 行为账本 | 未做 | 计划里本来就排在最后 |

**判定阈值**：少于 3 个字不参与打转判断（「好」「嗯」「在吗」本来就会重复）；三条回复两两字符包含度都 ≥ 0.6 才算绕圈。

**分类靠标题关键词**：`### 他明确要一段长的` = `long`。标题写得太文艺就认不出来，那份情境永不注入——那时把标题直接写成 `### long`。
